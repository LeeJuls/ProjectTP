# ⚔️ 전투 VFX 방향

> "3D 이펙트 vs 2D를 3D처럼" 질문에 대한 답. 상위: [[projectTP_허브]] · 에셋: [[에셋_후보_카탈로그]]
#projectTP/VFX

## 결론

**2D 픽셀 스프라이트가 주력, 3D는 보조.** 그리고 **이미 그 방향으로 가고 있다** — 현행 `T_FX_Hit`·`T_FX_Smear`가 텍스처+머티리얼 인스턴스 구조이고, Niagara 파티클 시스템은 프로젝트에 **0개**다.

## §1. 왜 2D 주력인가

| 근거 | 내용 |
|---|---|
| **아트 일관성 (결정적)** | 32px 도트 캐릭터 옆에 매끈한 3D 파티클(연속 알파·부드러운 그라데이션)이 있으면 **해상도가 다른 두 세계**가 한 화면에 놓인다. 픽셀 이펙트는 각진 질감·계단식 알파라는 고유 문법이 있고 그게 캐릭터와 같은 언어 — 튜닝으로 메울 수 없는 차이 |
| **파이프라인 무추가** | SubUV 플립북 머티리얼 · 픽셀퍼펙트 임포트 표준(TF_Nearest·NoMip) · 마스크드+양면+Lit 셰이더 전부 보유. Niagara는 완전히 다른 워크플로를 새로 익혀야 함 |
| **1인 개발 현실** | 픽셀 이펙트 스프라이트시트는 **사서 쓸 수 있다**([[에셋_후보_카탈로그]] 픽셀 VFX 팩 — 이미 180종 확보). Niagara는 파라미터 튜닝 비용이 크고 전담 아티스트가 없음 |
| **레퍼런스 정합** | HD-2D(옥토패스)는 "2D 스프라이트 + **3D 라이팅·파티클·깊이**"의 조합 — 이펙트 본체까지 3D로 만드는 방식이 아님 |

## §2. 3D가 담당할 영역 (명확히 있음)

> **핵심 통찰**: 옥토패스 개발팀은 일반 이펙트에 만족 못 하다가, **이펙트와 동시에 포인트 라이트를 켜서 캐릭터 그림자가 환경에 드리우게** 하자 훨씬 인상적이 됐다고 밝혔다. **"3D스러움"을 파는 건 파티클 지오메트리가 아니라 라이팅이다.**

| 요소 | 이유 |
|---|---|
| **순간 포인트라이트** ★최우선 | 파이어볼 터질 때 주황 라이트 점등 → 캐릭터·바닥에 실시간 그림자. **투자 대비 효과 최대** — 스프라이트 추가보다 싸고 체감이 큼 |
| **깊이 있는 잔재** | 먼지·불티가 캐릭터 앞뒤로 흩어져야 공간감 발생 |
| **화면 전체 효과** | 카메라 흔들림, 포스트프로세스 플래시 |

공통점: **형태가 없는 요소**라 픽셀아트 정체성이 불필요하고, 오히려 3D여야 자연스럽다.

## §3. 실행 구조

```
스킬 이펙트 본체(참격·화염·치유광)  →  2D 스프라이트시트 플립북   (현행 방식 확장)
        +
터질 때 순간 라이트 + 잔재          →  3D (라이트 액터 / 소량 Niagara)
```

**다음 단계 권고**: 현재 `Smear`+`Hit` 2종 → **스킬 5종별 전용 이펙트로 확장**. 조달처는 [[에셋_후보_카탈로그]]의 픽셀 VFX 팩(`Free/` 180종, 색상 변형 9종 내장 — 속성별로 색만 선택). **여기에 포인트라이트 점등 한 줄만 얹으면 체감이 크게 오른다**(순서상 라이트가 스프라이트 추가보다 우선순위 높음).

## §4. 판정된 것

- ❌ **Niagara 3D 파티클을 스킬 이펙트 본체로 쓰지 않는다** — 아트 일관성 붕괴
- ❌ **Godot 셰이더 팩([[에셋_후보_카탈로그]] Stylized Status FX)은 임포트 불가** — 포맷 비호환 + 스타일 불일치
- ⚠ **예외 지대**: 상태이상 지속 오라(독·기절)는 형태 없는 발광이라 부드러워도 덜 어색 — 필요 시 언리얼에서 직접 제작(외부 팩 이식 아님)
