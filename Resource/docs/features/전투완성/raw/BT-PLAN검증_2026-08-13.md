## 3. A1~A8 골격 판정 — **유효(V), 구조 변경 0건**

- **순서·의존 유지**: A0 완료 → A1 잔여가 **오너 항목 2건뿐**(F9b 육안·S1 런 사후확인) → FT트랙이 A1의 꼬리(F7b 재개)이자 **A2 구조 축의 선행 공사**(엔진 없이 1000풀 스킬을 실행 못 한다 — §4.6 판정 그대로 유효).
- **A1 실행 ∥ A2 설계 병렬 원칙**: 유효를 넘어 **지금이 실행할 때**다. A1의 에이전트 작업이 소진됐으므로(잔여=오너 몫) 설계 용량을 A2-B로 돌리는 §4.6 지시가 정확히 현 시점을 가리킨다.
- ★**A2-B1(요소 어휘)은 지금도 최우선 오너 게이트가 맞다** — 의존 사슬 `B1→S1→{S2∥B2∥B3}→S3→B4→A3`에서 B1이 유일한 진입점이고, §4.8b 실측대로 요소 데이터·조건 어휘가 현재 **0**이다. **단 병목의 실체는 "오너가 결재를 안 해서"가 아니라 "결재할 제안서가 아직 없어서"다** — 요소 체계 제안서(어휘·개수·상성 + `CondProperty` 확장안) 실물이 볼트에 없다. 에이전트 측 다음 수는 **B1 제안서 발주**(balance+system-ui, 오프라인·MCP 비경합)다.
- **A8 위치 정당**(알파 DoD 밖). 그리고 A8 제약 **P-2(커맨드 데이터화)의 실물이 바로 FT1 하네스**다 — *"지금 하면 한 줄, 나중엔 재작업"*이 FT1 우선순위를 한 번 더 지지한다.
- 골격 수정 권고: **없음.** 필요한 것은 §2-a 스테일 3건의 서술 정정(PM→sonnet 노동)뿐이다.

1군 육안 4건(WF·공격버튼·**F9b 한 판**·골드수지 대화) + 결재 6건(push · **문서구조 7단계 파일럿** · 보류 3파일 · PNG 57장 · 약칭 규약 · FT8 TC→재라벨로 축소) + ★**추가 편입 3건**(§2-c: D5.5 1차 struct 3종 · FT1-0b/0c 발화 확인 · B1 어휘 결재—제안서 준비 시). 0군 진입 조건은 §2-d대로 재서술.

### 문서구조 7단계(정본 통합) — 오너 결재 뒤, **A2-B 본격 착수 전이 최적**
