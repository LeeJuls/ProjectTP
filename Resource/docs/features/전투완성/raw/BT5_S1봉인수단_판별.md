### ★축3 불통과의 결정적 근거

```
F9a 캡처   c0091b1   2026-07-16 13:03   ← 구 고정 순환 큐 [A1,B1,A2,B2,A3,B3,A4,B4]
SPD 랜딩   c4f8695   2026-07-17 00:32   ← 11.5시간 뒤
```

그리고 **오라클 문서 자신이 §0.5에서 이 사실을 증거로 쓰고 있다** — *"23(구 순서) ≠ 20(SPD 순서) — 순서 변경이 원장을 바꾼다는 증거"*.

★**F9a 원장은 애초에 SPD 시나리오가 아니다.** 재계산으로 맞출 수 있는 게 아니라 **다른 게임**이다. 유닛턴 수부터 23 vs 20으로 다르다.

**7/8 통과, 1/8 실증된 불통과** → (a) 채택 불가.
