# 내장 트레일 채택 — 오너 육안 판정 (2026-08-12)

## ★오너 판정

> **"지운 게 훨씬 좋다."**

`SmearOffset.Z = -100000`으로 덧씌운 VFX 쿼드를 화면 밖으로 밀고 **heroes99 내장 트레일만** 남긴 상태를 라이브 PIE에서 육안 확인한 결과.

## 무엇이 밝혀졌나

### heroes99에 참격 트레일이 이미 들어 있다

별도 이펙트 폴더는 없다. 대신 **`weapon_top` 레이어의 공격 프레임 자체에 궤적이 그려져 있다.**

Pillow 실측 — weapon1 ATTACK1 6프레임 픽셀 bbox 면적:
```
208 → 196 → 740 → 588 → 126 → 128
              ↑     ↑
        로컬 3~4번째 프레임 = 트레일
```

- **무기 5종 전부**(sword×3 · spear · wand) 동일 패턴
- `weapon_bot`에는 해당 픽셀 **0** — 트레일은 top 레이어 전용
- ★**캐릭터와 같은 텍스처·같은 좌표계** → 위치·타이밍이 **정의상 어긋날 수 없다**
- `PlayAttack`이 이미 `RowIndex=5`(ATTACK1)를 재생 중 → **이 트레일은 계속 나오고 있었다**

### 그래서 오너가 본 "어긋난 이펙트"는 덧씌운 쪽이었다

| | 출처 | 밀도 | 위치 | 타이밍 |
|---|---|---|---|---|
| **내장 트레일** | heroes99 무기 레이어 | 캐릭터와 동일 | **정의상 일치** | **정의상 일치** |
| **덧씌운 Smear/Hit** | `_RawAssets/vfx/Free/`(itch.io 범용 180장) | **5.00 vs 6.48 = 0.77×** | 몸통 중심 고정 | 매직넘버 |

오너 증상 *"무기 가운데쯤에 뜨고 타이밍이 살짝 느리다"* — 전부 **덧씌운 쪽**의 성질이다.

## ★파급 (아직 미확정 — director 판정 대상)

| 대상 | 무엇이 흔들리나 |
|---|---|
| `vfx.csv` 5행 | `63000100 legacy_smear` · `63000200 legacy_hit`의 존재 이유 |
| `stagings` 4행 · `FxCastId`/`FxImpactId` | 3슬롯 설계가 legacy 2행을 전제로 짜였다 |
| `BP_BattleSpawnPoint` 잔상 서브체인 | 통째 제거 / 조건부 유지 / 트레일 기준 재정렬 |
| `SmearOffset` | 방금 만든 변수가 남을지 |
| D4.5b · D5 값 배정 | 재검토 범위 |

★**미확인 — 반드시 먼저 닫아야 한다**: `SmearOffset`은 **4곳 공용**(BeginPlay · 잔상 · 피격 HURT · 사망 DYING)이라, Z를 밀면 **피격 타격 이펙트도 같이 사라진다.** 오너가 판정한 화면은 **공격 잔상과 피격 이펙트가 둘 다 없는 상태**다. *"지운 게 좋다"*가 **공격만**인지 **피격까지**인지 구별되지 않았다.

## 재현 방법

```
8기 BP_BattleSpawnPoint 인스턴스 → SmearOffset.Z
  -100000 = 덧씌운 VFX 제거 (내장 트레일만)
       20 = 원래 상태 (둘 다)
```
레벨 저장 없이 인메모리로만 조작 — 리로드하면 BP 기본값 `(0,-80,20)`로 복귀.
