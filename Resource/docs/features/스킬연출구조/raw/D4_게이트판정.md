## 판정: **PASS (조건부)** — D4.5 착수 승인, D5는 조건 해소 후

진입 조건이던 **극단 8표본 표현 실증**은 충족됐다. qa 독립 검증으로 **프로필 4행이 30원자를 30/30 커버**(12+3+8+7, 미배정·중복 0)하고 **투사 7원자가 전부 `MAG`·`MotionRow=10`·`ENEMY1`이라 1행으로 충분**함이 확인됐다.

1차 D1을 막았던 Critical 4건(X1~X4)과 Director 실측 X5는 **2차 개정에서 5/5 해소**됐다.

## Director 라이브 실측 — 이 게이트에서 닫은 것

MCP 직접 조회로 D1이 미확정으로 남긴 항목 중 **3건을 닫았다**.

### Q2 확정 — X5 완전 증명

`DataTableTools.list_rows(/Game/Data/DT_Skills)` = **7행**:
`31000000` `31001000` `32001000` `33001000` `34001000` **`31002000` `31003000`**

`data/skills.csv`는 **5행**이다. 프루브 2행이 DT에만 있다.
→ **라이브 `DT_Skills`의 소스는 `skills.csv`가 아니라 `skills_v2_draft.csv`(7행)다.** X5 확정.

### Q1 확정 — `Kind`/`Target`/`Category`는 **FString**. 오너 세션 +0

`find_assets(/Game/Data)` 전수 = 애셋 13개:
`F_ActiveStatus` `F_JobStatsRow` `DT_JobStats` `F_MotionsRow` `DT_Motions` `F_SkillsRow` `DT_Skills` `Structs/F_SkillEffectRow` `DT_SkillEffects` `DT_StatusEffects` `DT_Strings` `F_StringsRow` `Structs/F_StatusEffectRow`

**UEnum 애셋이 하나도 없다.** 근거 3개로 FString 확정:
1. `/Game/Data`에 enum 애셋 0개
2. `get_schema`·`list_properties` 둘 다 `{"type":"string"}` — `integer`/`number`와 명확히 구분되어 표기됨
3. `search_row_structs("*")`가 **native struct만** 반환(사용자 BP struct 미포함) → 이 툴 계열은 타입 참조를 refPath로 노출하는데 `kind`엔 그것이 없다

→ **enum 애셋 3개 추가 불필요. 오너 세션 증가 0.**
→ 단 D1의 부수 확정은 유지: 패시브 `Category` 중립값은 **공란이 아니라 `NONE`**("없다"와 "안 채웠다"의 구별).

### Q8 확정 — DT 애셋은 MCP 생성 가능, struct는 오너 수동

- `DataTableTools.create(folder_path, asset_name, schema)` **존재** → DT 애셋 생성 **MCP 가능**
- 단 `schema` 인자가 struct를 요구하고, **struct 생성 툴은 어느 toolset에도 없다**(`search_row_structs`는 검색 전용)
→ **struct 6건 = 오너 수동 1세션 유지. `DT_Stagings`/`DT_Vfx`/`DT_Sfx` 애셋 생성은 MCP가 대행**한다.

### 부수 발견 — struct 폴더 관례가 갈려 있다

`F_SkillsRow`·`F_JobStatsRow`·`F_MotionsRow`·`F_StringsRow`는 `/Game/Data/` **루트**에, `F_SkillEffectRow`·`F_StatusEffectRow`는 `/Game/Data/Structs/` **하위**에 있다.
→ **신규 struct 6건의 배치 위치를 오너 지시서에 명시해야 한다.** 미정으로 두면 관례가 3갈래로 늘어난다. **권고: `Structs/` 하위**(최근 관례이며 루트 오염을 막는다).
