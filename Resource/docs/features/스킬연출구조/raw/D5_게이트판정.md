**채움 가능성이 이 단계의 시금석이었고 통과했다.** 42행 × 23컬럼 중 **미확정 924셀 0**. 남은 건 오너 결재 대기인 패시브 `Id` 10셀뿐이며 **10셀 치환으로 닫힌다**.

## ★balance가 plan 확정치를 더 조였다 — 승인

| 채널 | plan 확정 | **D5 확정** | 근거 |

| `OUT_MULT` | ≤ +0.10 | **≤ +0.04** | `floor(46×(1+v))−6 ≤ 41` → v<0.0435. **+0.05에서 딜 미러가 3타→2타** |

→ 이 조임이 **qa Z11(총턴 예산 붕괴)을 정확히 막았다.** `−0.10`이면 탱 미러가 6타가 되어 Z11이 현실화됐을 것이다. 실제 결과는 9매치업 전부 3~5타, 평균 3.56→3.89(+9.4%), 총턴 16~27로 광폭화 30 백스톱 내.

**신규 `PSV_*` StatusId 필수** — `ATK_UP`/`DMG_REDUCE`를 재사용하면 `REFRESH`가 영구값을 1턴짜리로 덮어 **패시브 영구 소실 + 막기 약화**가 난다.

## 판정 1 — "스탯 이전" **미적용 승인** (내 D0 판정의 정정)

D0에서 나는 *"패시브 스탯 조정은 가산이 아니라 이전"*으로 확정했다. **철회한다.**

- `(X, v)` 산출 자체는 성립한다(탱 `Def 11→8` + `IN_MULT −0.10` → 탱 미러 23 정확 복원, 칩락 마진 8→12 개선)
- 그러나 **UNIVERSAL 패시브가 3포지션 공용**이라, 이전을 적용하면 **P10을 뽑은 탱이 보상 없이 약해진다**(딜→탱 4→3)
- 이전이 성립하려면 포지션 풀 4개가 전부 방어축이어야 하고, 그건 **선택지 3→1 붕괴**다

→ **상한 강화로 대체한다.** 이전의 목적은 §7 검산표 무손상이었는데, **상한을 +0.04로 조이면 검산표가 애초에 흔들리지 않는다** — 원안의 목적을 더 강하게 달성한다.

## 판정 2 — §7-2 기준을 **"셀 불변" → "밴드(3~5) 불변"으로 재정의** 승인

여유 0인 셀이 3개다(서포터 미러 88/30=2.93 · 탱→딜 84/28=3.00 · 서→탱 108/27=4.00). 이건 **balance1 v1 자체의 잠복 취약점이며 패시브와 무관**하다 — 어떤 크기의 방어 패시브도 최소 1셀을 +1 이동시킨다.

→ 패시브가 만들지 않은 문제를 패시브에게 지울 수 없다. **밴드 불변이 옳은 기준**이다.

> ★**별건 기록**: `balance1_포지션킷_v1` §7-2의 **여유 0 셀 3개**는 이번 스코프 밖이지만 **어떤 미래 변경도 깨뜨릴 수 있는 잠복 취약점**이다. 잊지 않도록 여기 남긴다.

## 판정 3 — 투사 `FPS` **10 → 20 잠정 채택**, D6 오너 육안 확인 항목

`FPS=10`이면 투사 7원자의 `EstimatedTurnSec`이 **3.25s로 근접(1.80s)의 1.81배**다. `20`이면 1.85s ≈ 근접 1.80s로 정합한다.

단 **FPS는 룩을 바꾸는 값이라 최종 판단은 육안이다**([[2D배경_기각_교훈_2026-08-10]] — 아트 판정은 엔진에 세워보기 전까지 유보). 데이터라 되돌리기 쉬우므로 **정량 근거를 따라 잠정 채택**하고 **D6 임포트 후 오너 육안 확인 항목으로 등재**한다.
