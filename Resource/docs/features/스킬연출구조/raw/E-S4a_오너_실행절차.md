# E-S4a — 오너 실행 절차 (`F_SkillsRow` 6필드 추가)

> 상위: [[E_스파이크_plan]] · 판정 근거: [[E-S4a-0_struct자동화_조사결과]] · 이 절차가 [[D5.5_오너_struct세션_절차서]] §2차 ④의 **추가 6필드 부분을 대체**한다

## 무엇을 하나

`F_SkillsRow` struct에 **정수 필드 6개를 추가**한다. GUI에서 손으로 타이핑하지 않는다 — **스크립트 한 줄**이면 끝난다.

| 필드명 | 용도 |
|---|---|
| `stagingId` | 연출 프로필 FK |
| `fxCastId` | 캐스트 VFX FK |
| `fxProjectileId` | 투사 VFX FK |
| `fxImpactId` | 임팩트 VFX FK |
| `sfxCastId` | 캐스트 SFX FK |
| `sfxImpactId` | 임팩트 SFX FK |

**제거는 하지 않는다.** 구컬럼 10건 제거는 F7b ⑩a 게이트 GREEN 이후 별건이다.

## 결과 판정 — ★**마지막 줄만 보면 된다**

로그가 길게 나오지만 **맨 마지막 `[S4A_SKILLSROW_FX]` 줄**이 전부다.

| 마지막 줄 | 뜻 | 할 일 |
|---|---|---|
| `=== S4A SUCCESS ===` | ✅ 6필드 전부 들어감. **이미 저장까지 끝났다** | Claude에게 알리면 된다. **Ctrl+S / Save All 누를 필요 없다** |
| `=== S4A PARTIAL FAILURE ===` | ⚠ 도중 중단. **손상은 없고** 성공한 필드는 저장됨 | 로그 전체를 Claude에게 보고. 재실행하면 이어서 처리된다 |
| `=== S4A FAILED ===` | ❌ 시작도 못 함(플러그인 부재 등). **아무것도 안 건드렸다** | 로그를 Claude에게 보고 |

## 🚨 이 배너가 뜨면 — **아무것도 저장하지 마라**

```
!!! STOP — 지금 상태를 절대 저장하지 마라 (Ctrl+S 금지, Save All 금지) !!!
```

struct가 손상된 상태를 감지한 것이다. **스크립트는 저장하지 않고 멈췄으므로 디스크는 아직 멀쩡하다.** 여기서 저장하면 그게 깨진다.

1. **저장하지 마라** — Ctrl+S도 Save All도
2. 언리얼 에디터를 **저장하지 않고** 종료
3. 복구:
```bash
git -C D:/unreal/projectTP/Content checkout -- Data/F_SkillsRow.uasset
```
4. 로그 전체를 Claude에게 그대로 보고

> 발생 확률은 매우 낮다(가산 전용 작업). 다만 [[D5.5_오너_struct세션_절차서]] 공통주의 ④가 *"저장은 Ctrl+S, Save All"*을 지시하고 있어, **습관대로 저장하면 안전장치가 무효화**되기 때문에 명시한다.
