## 실행

에디터 상단 메뉴 → **Window → Output Log** → 하단 입력창의 드롭다운을 **`Cmd` → `Python`** 으로 바꾼다.

### ~~★먼저 — 틱 스로틀 해제 (한 줄, 5초)~~ → ★스테일(2026-08-12 정정, [[언리얼_MCP_실전노하우]] §40 · [[야간작업_2026-08-12]] 정정①)

★★**이 절은 no-op다 — 실행해도 타이밍 검증은 살아나지 않는다.** 아래는 원문 그대로 남기되(판단 과정 보존) 결론만 먼저 읽을 것:

> `bThrottleCPUWhenNotForeground`는 **원래부터 `false`**였다(§39의 "기본값 `true`가 적용 중"이라는 진단 자체가 틀렸다 — ini 파일만 보고 런타임 값을 확인하지 않은 오진). 아래 스크립트를 실행해도 `false → false`로 **아무것도 바뀌지 않는다.**
> ★**진짜 원인은 이 설정이 아니라 "에디터 창이 백그라운드 상태"라는 구조적 조건**이다(§41 확정 — 사람이 앞에 있으면 60fps, 에이전트가 PIE를 돌리면 3fps, 에이전트는 이 조건을 바꿀 수 없다). 이 조건은 Python 콘솔 한 줄로 해소되지 않는다.
> **오너가 이 스크립트를 실행하고 `SUCCESS` 메시지를 봐도 "이제부터 타이밍 검증이 가능해졌다"는 뜻이 아니다** — 세션이 background로 열리는 한 여전히 3fps다.

```
s = unreal.get_default_object(unreal.EditorPerformanceSettings); s.set_editor_property('throttle_cpu_when_not_foreground', False); s.save_config()
```

~~**왜 여기서 하나**: 이 설정이 켜져 있으면 PIE가 **초당 3틱**으로 제한돼 `Delay`·비동기 로딩이 사실상 진행되지 않는다. E-S2에서 이것 때문에 검증 5건이 막혔고, 에이전트가 *"타이밍 로직을 MCP로 검증할 수 없다"*는 잘못된 결론까지 갔다([[E-S2_틱스로틀_진단]]).

콘솔을 어차피 여시는 김에 같이 처리하면 **이후 전 단계의 타이밍 검증이 살아난다.** 부작용은 에디터가 백그라운드일 때 CPU를 더 쓰는 것뿐이다.~~

★**정정**: E-S2의 검증 5건이 막힌 원인은 이 설정이 아니라 위 구조적 조건(백그라운드 3fps)이었다. 이 한 줄은 **해도 그만 안 해도 그만인 no-op**이며, 굳이 실행해서 해가 될 것은 없으나(이미 `false`이므로) **타이밍 검증 문제의 해결책이 아니다.** 실제 우회책은 [[자율진행_plan_v2]] FT1(검증 하네스)의 자동 시작 토글 등 별도 트랙에서 다룬다.

> `save_config()`가 빠지면 이번 세션만 적용되고 재시작 시 되돌아간다. 위 한 줄에 포함돼 있다(단, 위 정정대로 실행 자체가 효과 없음에 유의).

## 결과 판정 — ★**마지막 줄만 보면 된다**

로그가 길게 나오지만 **맨 마지막 `[S4A_SKILLSROW_FX]` 줄**이 전부다.

| 마지막 줄 | 뜻 | 할 일 |
|---|---|---|
| `=== S4A SUCCESS ===` | ✅ 6필드 전부 들어감. **이미 저장까지 끝났다** | Claude에게 알리면 된다. **Ctrl+S / Save All 누를 필요 없다** |
| `=== S4A PARTIAL FAILURE ===` | ⚠ 도중 중단. **손상은 없고** 성공한 필드는 저장됨 | 로그 전체를 Claude에게 보고. 재실행하면 이어서 처리된다 |
| `=== S4A FAILED ===` | ❌ 시작도 못 함(플러그인 부재 등). **아무것도 안 건드렸다** | 로그를 Claude에게 보고 |

> ★**"빨간 에러가 안 떴으니 성공"으로 판단하지 마라.** 이 스크립트는 예외를 로그로만 남기고 REPL에 빨간 줄을 안 띄울 수 있다. **마지막 줄이 유일한 판정 기준**이다.

1. **저장하지 마라** — Ctrl+S도 Save All도
2. 언리얼 에디터를 **저장하지 않고** 종료
3. 복구:
```bash
git -C D:/unreal/projectTP/Content checkout -- Data/F_SkillsRow.uasset
```

4. 로그 전체를 Claude에게 그대로 보고
