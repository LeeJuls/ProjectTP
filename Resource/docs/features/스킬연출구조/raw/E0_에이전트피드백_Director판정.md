## Director 판정 5건

### 판정1 — 밀도 해법 **격하** (답 없음을 인정)

| 스테이징 | 컷 | 라이브 7행 | 배정 VFX |
|---|---|---|---|
| `62000100` 근접 | TRUE | 4행 | FxCast **0** · Impact legacy(0.77×) — 문제 없음 |
| `62000200` 도약 | TRUE | **0행** | — |
| `62000300` 원거리 | **FALSE** | `32001000` | **신규 3장(0.58×)** ← 문제 |
| `62000400` 지원 | **FALSE** | 2행 | **신규(0.58×)** ← 문제 |

→ *"근접은 애초에 문제없음 / 원거리·지원은 **미해결**"*로 정직하게 격하. **S5에 `IsCameraCut` 런타임 오버라이드 노브**를 넣어 S6에서 실험으로 답을 찾는다.

부수: *"옵토패스도 같은 방법으로 푼다"*는 **근거 없음**으로 격하 — 그쪽 컷은 연출적 강조이고, **처음부터 캐릭터 밀도에 맞춰 제작**했을 가능성이 높다(전제가 다르다).

### 판정2 — 관통 판정값 `62000300` → **`62000200`** 【승인】

`62000300` = `0.0/-1/0.0/FALSE/TRUE` vs struct 기본값 `0.0/-1/0.0/false/false` → **1비트 차이**.
`62000200`(`1.0/4/-1.0/TRUE/TRUE`)만이 폴백값·기본값 양쪽과 전 필드가 다르다. **3중 구별**(정상행/폴백/빈 struct)로 승격.

### 판정3 — S4b는 **MCP `set_rows` 고정, CSV 재임포트 금지** 【승인】

라이브 `DT_Skills` = **23필드/7행**(프루브 포함) vs `data/skills.csv` = **15컬럼/5행**.
→ 재임포트하면 **프루브 2행 + 8필드 소실** → **F7b ⑧(프루브 E2E 게이트) 실행 불가**.

### 판정4 — S0 노드 목록 **15종** 확정

qa 12종 + gameplay 3종. ★실증 없는 것: **외부 raw 변수 Get** · `SetTextureParameterValue`의 **declaring_class** · `InputKey` 이벤트(검출 실패→폴링 대체) · **`AlignSpriteToCamYaw` 호출**(R3 전제) · **`PlayHurtReaction` 호출**(FLINCH 전제).

### 판정5 — **struct 자동화 조사(S4a-0)를 앞에 넣는다**

가능하면 **오너 세션 0**, 불가하면 수동. ⚠ 스크립트 결함 2건(멱등 가드 과광범위, `names[-1]` 가정)을 먼저 고쳐야 한다.
⚠ 수동이면 **오너 세션 2→3회 증가** → [[D5.5_오너_struct세션_절차서]] §2차 표에 *"추가 6은 E-S4a에서 완료 — ⑩a는 제거 10만"* 반영 필요(안 하면 오너가 중복 추가를 시도한다).

## ★DoF 누락 (hd2d)

**틸트시프트 DoF는 HD-2D 시그니처 축**인데 노브 목록에 없었다. [[S5_룩패스]]에 B안 값(FocalDistance 1100 / Region 250 / Transition 300·400 / Blur 3.0)이 **이미 측정됐는데 원복돼 꺼진 채** 저장돼 있다.

→ **실험 노브가 아니라 클론의 baseline으로 켠다.** 안 켜면 *"옵토패스 같지 않다"*의 원인이 **VFX인지 DoF 부재인지 분리 불가** — [[2D배경_기각_교훈_2026-08-10]]의 *"판정을 오염시키는 누락 변수"* 함정.

## 연출 요소 카테고리 정정 (hd2d)

- **"옵토패스풍 3종"은 혼동** — **포인트라이트만 HD-2D 룩**에 직접 해당. 히트스톱·셰이크는 범용 액션 기법("타격감"이지 "룩 정체성"이 아니다)
- **스프라이트 아웃라인은 빼라** — 옥토패스는 **외곽선 없는 라이팅 음영**이 핵심. Director가 든 예시가 오해였다
- **포인트라이트는 `CastShadows` 명시 필수** — 기본값이 아니다
- ★**셰이크 ↔ 빌보딩 충돌** — 스냅은 2시점, 셰이크는 연속 워크 → 컷 중 셰이크면 **"종이 효과" 재발**. [[카메라연출_원칙]]이 예견

## ★이 스파이크의 유효범위 (S6 산출물에 필수 고지)

> **정지화면 품질(룩)은 유효하게 판정한다. 시간 결합(타이밍·판정·사망)은 판정하지 못한다.**

놓치는 것 12건 중 대표: 라이브 exec 위상(Delay 4단 + `PlayAttack` ~0.58초 블록) · **임팩트 FX 시각 ↔ 데미지 판정 시각의 분리**(데미지가 없어 원리적으로 관측 불가) · **라이브에서 3슬롯을 어떻게 만드는가**(패리티 토글은 차이를 재기만 하고 해법을 내지 않는다) · 시간 밀도 비교(외부 Get만으로는 캐릭터 모션을 재생 못 시킨다) · 사망·멀티히트·SFX 전량.

★**고지하지 않으면 2D배경 때와 같은 "판정 → 엔진에서 기각" 패턴이 한 층 위에서 재발한다.**
