## 3. ② 패시브 10 설계 + 상한 산술

### 3-1. 표현 가능 공간이 3축뿐이라는 사실부터

린트 **L05b**(`#Layer==PASSIVE → TargetGroup=="SELF"`) + `Channel` 4종(`SKIP_TURN`/`DOT`/`OUT_MULT`/`IN_MULT`) + `EffectType`(`DAMAGE`/`STATUS`/`HEAL`)을 곱하면 알파 패시브가 표현할 수 있는 것은 **정확히 3축**이다.

| 축 | 표현 | 훅 | 카운터 |
|---|---|---|---|
| **A 공격** | `STATUS` → `SELF_BUFF/OUT_MULT/ATK/+v/-1` | `ON_BATTLE_START` | **없음** |
| **B 방어** | `STATUS` → `SELF_BUFF/IN_MULT/DEF/−v/-1` | `ON_BATTLE_START` | **없음**(단 BURN이 관통) |
| **C 지속** | `HEAL` `ScaleMode=ATK` `Value=v` | `ON_TURN_START` | ★**STUN**(D1 §7-2) |

- `SKIP_TURN` 자기부여 = 자해, `DOT` 자기부여 = 자해 + BURN이 STUB → **둘 다 미사용**.
- 적 대상 패시브는 L05b가 구조적으로 금지 → 카운터 관계는 **A/B/C 사이가 아니라 "액티브가 패시브를 무는" 방향으로만** 성립한다.
- ★**`ON_TURN_START` 훅은 밸런스 여유를 주지 않는다**: 그 버프는 소유자가 행동하는 모든 턴에 켜져 있으므로 TTK 계산상 영구형과 **동일**하다. 훅의 가치는 **STUN 카운터 1개를 만드는 것**뿐이다 → 훅을 "크기 레버"로 쓰지 않고, **효과 성질(회복은 턴 단위)에 따라서만** 배정했다.

### 3-3. ★상한 산술 — 상한을 정한 것은 무원킬이 아니라 **미러 TTK**다

plan 확정 상한은 `Atk +7%(보수)/+15%(절대)` · `OUT_MULT ≤ +0.10`이었다. 실제로 채워보니 **그 훨씬 아래에서 다른 게이트가 먼저 깨진다.**

**A축(공격) 상한 유도 — 딜 미러 3타가 binding**

```
딜 미러 평타: floor(46 × 1.0 × (1+v)) − 6  ≥ ceil 기준  →  TTK = ceil(84 / dmg)
TTK 3 유지 조건: dmg ≤ 41  →  floor(46(1+v)) ≤ 47  →  46(1+v) < 48  →  v < 0.0435
```

| v | 딜 미러 1타 | TTK | 파이어볼 단일타(vs 딜84) | 판정 |
|---|---|---|---|---|
| 0 | 40 | 3 | 72 (마진 12) | 기준 |
| **+0.04** | **41** | **3** ✓ | **75 (마진 9)** | ★**채택** |
| +0.05 | 42 | **2** ✗ | 76 | 미러 붕괴 |
| +0.07 (plan 보수) | 43 | **2** ✗ | 77 (마진 7) | 미러 붕괴 |
| +0.10 (plan 절대) | 44 | **2** ✗ | 80 (마진 4) | 미러 붕괴 |
| +0.16 | 47 | 2 | **84 = 원킬** | 무원킬 붕괴 |

> ★**무원킬 게이트(+0.16 붕괴)보다 미러 TTK 게이트(+0.05 붕괴)가 3배 이상 먼저 온다.** plan·qa가 수렴했던 "+0.15~+0.20에서 붕괴"는 **무원킬 축만 본 결과**였고, 그 축에서는 지금도 맞다(§4-1에서 재확인). 하지만 **실제 상한은 그것이 아니다.**

**B축(방어) 상한 유도 — 탱 미러 5타가 binding**

```
탱 미러 평타: floor((34 − 11) × (1−v)) = floor(23(1−v))
TTK 5 유지 조건: dmg ≥ ceil(108/5) = 21.6 → 22  →  23(1−v) ≥ 22  →  v ≤ 0.0435
```

| v | 탱 미러 1타 | TTK | 판정 |
|---|---|---|---|
| 0 | 23 | 5 | 기준 |
| **−0.04** | **22** | **5** ✓ | ★**채택** (`PassiveInMultFloor = −0.04`) |
| −0.05 | 21 | **6** ✗ | 밴드 이탈 |
| −0.10 | 20 | **6** ✗ | 밴드 이탈 |

**C축(회복) 상한 유도 — 탱 미러가 다시 binding**

```
탱 미러 실질: 23 − r ≥ 22  →  r ≤ 1  →  floor(34 × v) ≤ 1  →  v ≤ 0.0588
```
→ **`v = 0.05` 채택.** 딜(Atk46)은 2/턴, 서(Atk38)·탱(Atk34)은 1/턴. 딜 방어측 binding은 `서→딜 32−r ≥ 28 → r ≤ 4`라 2/턴은 여유 안.

### 3-5. ★"스탯 이전"은 구조적으로 성립하지 않는다 — `(X, v)` 산출과 기각
