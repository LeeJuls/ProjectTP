## ★Director 판정 (qa 요구 5건)

### 판정1 — 밀도 해법은 **답이 없다.** 격하한다 (E-C1)

당초 *"액션 캠 컷에서만 크게"*라고 썼는데 **적용 대상이 0개**다:

| 스테이징 | 컷 | 라이브 7행 | 배정 VFX |
|---|---|---|---|
| `62000100` 근접 | **TRUE** | 4행 | FxCast **0** · Impact `legacy_hit`(0.77×) — **문제 없음** |
| `62000200` 도약 | TRUE | **0행** | — |
| `62000300` 원거리 | **FALSE** | `32001000` | **신규 3장(0.58×)** ← 문제 |
| `62000400` 지원 | **FALSE** | 2행 | **신규(0.58×)** ← 문제 |

→ **컷이 켜진 스킬은 전부 legacy, 신규 VFX는 전부 컷 없는 스킬.** 완화책이 문제에 도달하지 않는다.

**판정**: plan의 "답"을 **철회**하고 *"근접 계열은 애초에 문제없음 / 원거리·지원은 **미해결**"*로 정직하게 격하한다. 대신 **S5에 `IsCameraCut` 런타임 오버라이드 노브**를 넣어 S6에서 실험으로 답을 찾는다. **답을 찾는 게 실험대의 목적이지 답을 미리 아는 게 아니다.**

부수: *"옵토패스도 같은 방법으로 푼다"*는 **근거 없음**으로 격하(hd2d) — 그쪽 컷은 연출적 강조이지 밀도 충돌 은폐가 아니고, **처음부터 캐릭터 밀도에 맞춰 제작**했을 가능성이 높다.

### 판정2 — 관통 판정값을 **`62000200`으로 교체** (E-C2) 【승인】

`62000300` = `0.0 / -1 / 0.0 / FALSE / TRUE` 인데 **`F_StagingsRow` struct 기본값이 `0.0 / -1 / 0.0 / false / false`**다.
→ **조회 실패로 빈 struct를 받아도 1비트만 다르다.** R7 완화책이 R7에 걸린다.

**`62000200`**(`1.0 / 4 / -1.0 / TRUE / TRUE`)만이 폴백값·기본값 **양쪽과 전 필드가 다르다.** 그리고 **3중 구별**(정상행 / `DefaultStagingId` 폴백 / 빈 struct)을 판정 기준으로 승격.

## 3대 불일치 (아트 실측)

### ① 공간 밀도 — 위험이 아니라 **트레이드오프**

| 대상 | uu/텍셀 | 캐릭터(6.48) 대비 |
|---|---|---|
| legacy VFX (쿼드 2.4) | 5.00 | 0.77× |
| **신규 VFX (쿼드 2.4)** | **3.75** | **0.58×** |

`Plane` 로컬 바운드 **정확히 100×100uu** 실측 확정. 등가 스케일 = **4.15**.

> ★**4.15는 "크리스프니스 동일화" 값이지 "화면 크기 유지"가 아니다.** 2.4를 그대로 두면 쿼드는 legacy와 같은 240uu라 **오버랩이 자동으로 발생하지 않는다.** → *"이웃을 덮는다"*는 **4.15를 선택했을 때만 생기는 자기유발적 결과**다.

★**스케일 노브는 전역 1값이 아니라 `vfxId`별 오버라이드**여야 한다 — 등가 배율이 **legacy 1.30× / 신규 1.73×**로 달라 하나로는 둘을 동시에 못 맞춘다(E-H9). 전역이면 4.15에서 **legacy가 0.77→1.33×로 캐릭터보다 커진다**.

### ② 시간 밀도

캐릭터 **8fps** / legacy **10** / 신규 **20**. 한 화면에 세 리듬. **8 또는 16(정수배)**이 프레임 경계까지 맞는다 — 육안 판정.

### ③ 블룸 — 수치는 맞고 **원인 가설이 틀렸다**

|  | RGB>200 | 프레임당 **최대 채움 면적** |
|---|---|---|
| legacy Hit | **100%**(신규보다 밝다!) | **14.4%** |
| cast_atk row0 | 85.3% | **45.4%** |

→ 원인은 휘도가 아니라 **연속된 밝은 면적**. legacy가 문제없던 건 **덩어리가 작아서**다. 처방(`EmissiveBoost` 3.0→1.0)은 유효.
부수: 파일별 최대 채움이 **17~45%로 3배** 차이 → 단일값 통일 튜닝 불가, **파일별 미세조정 여지**를 연다.

## ★DoF를 baseline으로 켠다 (hd2d)

**틸트시프트 DoF는 HD-2D 시그니처 축**인데 노브 목록에 없었다. `S3_룩패스`에 B안 값(**FocalDistance 1100 / Region 250 / Transition 300·400 / Blur 3.0**)이 **이미 측정됐는데 원복돼 꺼진 채** 저장돼 있고 fxlab이 그대로 복제한다.

→ **실험 노브가 아니라 클론의 baseline으로 먼저 켠다**(측정 완료라 비용 0). 안 켜면 *"옵토패스 같지 않다"*의 원인이 **VFX인지 DoF 부재인지 분리 불가** — 2D배경이 남긴 *"판정을 오염시키는 누락 변수"* 함정이다.

## 연출 요소 — 카테고리 정정 (hd2d)

- **"옵토패스풍 3종"은 혼동**: **포인트라이트만 HD-2D 룩**에 직접 해당. 히트스톱·셰이크는 **범용 액션 기법**("타격감"이지 "룩 정체성"이 아니다)
- **스프라이트 아웃라인은 빼라** — 옥토패스는 **외곽선 없는 라이팅 음영**이 핵심. 내가 든 예시가 오해였다
- **포인트라이트는 `CastShadows` 명시 필수** — 기본값이 아니다. 랜턴 RectLight 선례 있음
- ★**셰이크 ↔ 빌보딩 충돌**: 스냅은 **2시점**, 셰이크는 **연속 워크** → 컷 중 셰이크면 **"종이 효과" 재발**. [[카메라연출_원칙]]이 예견. 진폭이 작으면 안 보일 수도(미확인)

**노브는 군별 순차 개방**: 1군 스케일+Emissive → 2군 타이밍 → 3군 임팩트 → 4군 PPV. 15개 동시 노출은 원인 분리를 불가능하게 한다.
