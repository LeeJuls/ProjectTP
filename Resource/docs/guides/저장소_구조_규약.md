## 3. 왜 이렇게 나눴나

| 결정 | 사유 |
|---|---|
| 게임 소스 = 공개 | 오너 방침 — 소스는 공개 유지 |
| 유료 에셋 = 비공개 | **재배포 금지 라이선스**. 공개 저장소에 원본을 올리면 위반 |
| `Content/` 분리 | 유료 임포트분 포함 + 1.4GB 대용량 + 부모가 이미 ignore 중이라 자연 분리 |
| `_RawAssets/` 분리 | 원본 압축파일까지 포함 — **비공개라도 재배포 성격**이라 원래 커밋 대상이 아니었으나, 오너가 "에셋도 커밋" 결정(2026-07-26) → 비공개 전용 저장소로 |
| LFS 사용 | 바이너리 대용량. GitHub 무료 한도 10GB(현재 2·3번 합계 ~1.5GB) |

## 6. 주의

- **`D:\unreal\docs\`(stray)** — `Resource\docs\`와 다른 폴더. 미추적 상태이며 **작업 대상 아님**. 볼트는 `Resource\docs\`뿐
- **git-lfs PATH** — PowerShell 세션에서 인식 안 될 수 있음:
  `$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine")+";"+[Environment]::GetEnvironmentVariable("Path","User")`
- **LFS는 커밋 성공 ≠ 업로드 성공** — push 후 `git lfs ls-files`의 `*` 마크로 원격 저장 확인
