## 2. ★무거운 판정 3가지

### (가) SCF + 트리거 벽 → **FT1 "검증 하네스" 신설**

★**둘은 같은 문제의 두 얼굴**이다 — F트랙의 실증 TC 전부가 *"PIE에서 임의 발화"*를 요구하는데 **그 수단이 없다.** 개별 우회 대신 한 단계로 묶는다.

**FT1 = MA 훅(1a) + 자동 시작 토글(1b) + SCF 호출기(1c)**. 셋 다 `BP_BattleManager` 계열 **additive 스캐폴드**로 성격이 같다.
- **커밋·세이브포인트는 3분리**(롤백 경계 원칙), 게이트는 FT1 하나
- ★**자동 시작 토글을 F트랙 필수로 승격** — 없으면 FT2~FT8의 모든 실증이 **케이스마다 오너 클릭 1회**에 걸려 세션 경제가 붕괴한다. *"막힌 지점이 정확히 1개"*라는 A1 실측이 이 투자의 근거

### (나) H18 측정 아티팩트 → **오너 세션 로그 재활용으로 닫는다**

가설 B(블록 없음 + 3fps 양자화)는 독립 교차 지지로 유력하나 **미확정**. 3fps에서 원리적 검증 불가도 수용.

★**해법은 계측 추가가 아니라 이미 확보될 로그의 재활용**이다 — 오너 세션은 **60fps**(A1 실측)이므로 F9b 런 로그의 `ExecWalkPhase→TurnEnd` 델타 **하나로 가설 A/B가 갈린다.** **오너 추가 노동 0.**

그때까지 ★**`SlotBudgetSec` 확정 금지**를 자율 경계에 신규 편입(3.0 vs 2.1 = **43% 차이**가 D6 설계 전체를 흔든다). 타이밍 상수 소비 지점은 전부 **"미정" 표기**.

### (다) 런지 인과 역전 → 영향 판정

| 대상 | 영향 |
|---|---|
| **FT2~FT8** | **0** — 인터프리터·애플리케이터는 `IsAttackFamily`와 무관 |
| **D6** | **구조 변경 0, 근거 정정만.** C4의 잔상 이중게이팅 축은 여전히 참, C5/I2는 **오히려 강화** |
| **BT1 정정 절**(문서 9개·20지점) | ★**사실확인 결과 도착 후 실행** — 이 오류의 원인이 *"실측 없이 서술 복제"*였으므로 **정정도 실측 인용을 기다린다** |

## 5. 자율 경계 v2

★**FT1 하네스는 K3 비해당 — 자율 승인.** 단 **4제약 하에서만**:
1. **additive 전용**(기존 exec·핀 절단 **0**)
2. 발화 게이트 = Instance Editable bool 기본 **`false`**(off 시 라이브 경로 무변)
3. 롤백 = 발화 지점 exec 절단 1개 + **3커밋 각각 세이브포인트**
4. **S1 봉인 확보 후 착수**

★**제약 위반이 필요해지는 순간 — 예: 기존 노드 절단이 불가피 — 그 자리에서 정지, 오너 게이트로 격상.**
